Where to start

The smallest number on this board is 1, and there are 3 of them. The smallest number can only ever merge with an equal neighbour or a wildcard, because everything else only gets bigger, so work out where those go first. The 1 in row 1, column 5 has only one possible partner, the 1 in row 1, column 4, so that pairing is forced.

Wildcards

This level has 1 wildcard: ×2. Each merges with any number, but never with another wildcard.

Watch out for

There are 5 trap pairs on this board: two equal numbers side by side where merging them either way leaves a circle that can never be finished. Before each merge, check that every neighbour of the two circles still has a partner afterwards.
