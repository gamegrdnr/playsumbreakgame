Where to start

The smallest number on this board is 2, and there are 8 of them. The smallest number can only ever merge with an equal neighbour or a wildcard, because everything else only gets bigger, so work out where those go first. The 2 in row 1, column 1 has only one possible partner, the 2 in row 2, column 1, so that pairing is forced.

Wildcards

This level has 2 wildcards: +3, +3. Each merges with any number, but never with another wildcard. The 125 and 509 are outside the 1, 2, 4, 8 sequence, and each starts next to the wildcard that brings it back.

Watch out for

There are 8 trap pairs on this board: two equal numbers side by side where merging them either way leaves a circle that can never be finished. Before each merge, check that every neighbour of the two circles still has a partner afterwards.
